# AI render loop / raea
Sources: https://github.com/shinyobjectz/raea and https://github.com/shinyobjectz/raea-skills. Engine FSL-1.1-ALv2; official skill repository Apache-2.0; review actual dependency and plugin licenses. No engine source is copied into GameKit. Native raea 0.1.6 is an optional experiment, not a required migration; keep target browser/WebGL2/WebGPU/native build.
Use a renderer adapter: capabilities(), prepare(recipe,seed), capture(camera,frame,viewport), replay(inputs,seed), metrics(), dispose(). Record backend, GPU, driver, build hash, seed, timestep, camera, lighting, viewport, quality tier and evidence path. Capture target backend, not an unrelated renderer as proof. Deterministic seed + fixed timestep for regression; separate real-time stress tests.
If capable, capture actual target views with project-specific stop budget; otherwise hand off VISUAL_PENDING under environment-evidence.md. A reviewer need not be the implementing AI. No fake evidence.
Native raea optional: review and pin release and checksums; install using upstream official instructions on capable host; raea --help, raea doctor if supported; raea render scene.tsx -o frame.png --frame 45, raea play scene.tsx, raea render scene.tsx -o scene.mp4, raea check scene.mp4 (confirm CLI help). Official plugin: /plugin install raea --marketplace shinyobjectz/raea-skills (review hooks, pin version); or raea skills install --agent NAME. Read official guides from installed CLI. Never run remote installer in KV or chat-only runtime. If native renderer unavailable, use existing browser target with Playwright screenshot/WebGPU GPU runner or a suitable native target runner; software fallback must be labeled and final device test still required.
Architecture: TS/React declarative presentation where useful, deterministic simulation independent of renderer, native Rust/WASM CPU kernels only as measured, WGSL GPU kernels when appropriate; K language experimental pending compatibility, no forced transpiler. Strict code-only asset rules override raea's model/texture/footage/AI-media import features. Screenshots are QA artifacts, never runtime assets.
