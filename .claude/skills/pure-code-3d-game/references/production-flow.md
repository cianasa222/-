# 按实际项目决定制作投入

## 一、先验证游戏是否值得继续做

用一句话描述玩家反复做的决定，再描述为什么下一次会不同。给原型设可推翻的假设。例如，路线游戏的选择能否在半秒内读懂，卡牌游戏的两张牌是否导致不同策略。先造一个房间、一场遭遇或一道谜题。观察第一次按键、第一次犯错、第一次主动重试；做玩法结论后再扩充资产。无胜负的沙盒可观察自定目标与再次行动的动机，不必强加结算。

## 二、输入、相机和时间是玩法的一部分

将设备动作映射为逻辑意图；处理按下/释放、焦点切换、菜单抢占、失去焦点时清除长按、手柄拔插与触控取消。设置灵敏度、死区、长按/切换按项目需求决定。每种承诺设备从启动到退出至少能独立操作。动作游戏在固定输入回放下测输入到首个可见反馈；回合制锁行动顺序和撤销，节奏游戏以音频时钟为基准，联机明确权威时钟与重连恢复。不要把所有逻辑绑在渲染帧。

| 呈现方式 | 优先测的一件事 |
|---|---|
| 第一人称 / VR | 近裁剪、手持物遮挡、视野/舒适度；XR 另测立体深度、交互距离与目标设备帧预算 |
| 第三人称 / 越肩 | 靠墙转身时镜头是否穿墙，目标被遮住时是否恢复可见 |
| 横版 / 平台跳跃 | 起跳与落点是否可读，向前看范围、镜头死区和输入宽容是否一致 |
| 俯视 / 战术 / 大规模策略 | 单位在缩放后的可辨性、选择优先级、危险区与 UI 是否互相遮挡 |
| 竞速 / 飞行 | 高速路径预读，地标和弯道，镜头响应、世界流入及低帧下碰撞 |
| 卡牌 / 棋盘 / 文字 | 操作焦点、文字层级、撤销、信息揭示顺序、存读后的逻辑状态 |
| 多镜头 / 观战 / 过场 | 控制权交接，跳过或中断后状态是否一致，视角切换是否改变规则 |

## 三、首局教学、内容生产与数值

首局用动作和反馈教规则；误操作可以撤回或重试，失败能看出原因。陌生玩家看不懂时先改信息表达。为关卡、遭遇、任务、对话等建立稳定 ID，检查无效引用、死路、无法抵达的目标和循环奖励。第二关/第二个角色用已有流水线做一次，记录实际制作耗时与质量差异，再决定产量和范围。随机地图固定种子批量跑可达性与极端样本，保留失败种子和生成器版本。

对成长和经济分别记录单位时间获得、消耗、通关时间与奖励触发来源。奖励重复回调、拾取跨级、稀有掉落极端样本进入自动回归。同一组数据比较新人和熟练者的选择分布；均值无法表达连续卡关。没有成长或经济的游戏直接略过这些检查。

## 四、状态和存档从早期就定边界

明确暂停究竟冻结哪些时钟，重试会重置哪些状态。设置、账号、本局临时状态和长期进度分开；序列化稳定 ID 与存档版本。测试保存→退出→读回、写入中断、旧版升级、损坏恢复。首次发行也可保留一个历史模式夹具；从第二版开始必须有上一发行版的真实档。为当前存储选择原子替换、事务或双槽提交，写好再切指针；覆盖前保留可恢复版本。云存档另定冲突处理。热修复回退要考虑新版存档的可读性，必要时恢复兼容服务或用已验证备份。纯本局游戏把“结束后不保留什么”写清即可。

## 五、音频、界面与可访问性

划分音乐、环境、语音和反馈优先级，限制同时播放数量，切后台或重复进出关卡时检查声音叠放。按钮反馈与实际状态变更同源。关键危险与选中状态至少测试静音、低对比/颜色辨识受限情形；根据玩法提供视觉、声音、形状、触感中的替代提示。字幕、关键文字尺寸、震屏/闪烁/镜头摆动、按键重映射按承诺启用。游戏 UI 要经历长文本、字体缺失、异形屏、窗口缩放、手柄焦点和空状态等实际对应的情况。完全声音驱动的玩法需单独定义可行的目标和验收，不把替代方案写成不可能的承诺。

## 六、性能、稳定、上线与维护

按瓶颈分别量输入响应、CPU 模拟、GPU/合成、IO 与初次可交互时间；用帧时间分布看卡顿。回合制可优先量行动响应，大世界看流入峰值，UI 游戏看文字布局和内存。热机持续运行、连续十次进出关、窗口/后台恢复、断网与空间不足按平台取样。一次高端机的平均 FPS 不足以验收最低配置。记录场景、设备、系统、构建、采样窗口和误差。

准备首装、升级、回退/重新安装路径。验证用户设置和进度在承诺范围内保留，保存符号/错误日志、构建与资源摘要，标明已知问题。线上多人需声明断线、命令幂等、房间恢复、客户端/服务版本兼容；只有实际使用在线服务时才考虑账号和遥测。发布实际包含的代码库、字体、样本和生成数据都要核来源与授权。版本投放后能凭构建、种子、输入或日志定位故障；反馈优先用于复现和验证假设。

## 七、开发 AI 的交付顺序

任务卡写玩家可观察目标、输入和可改路径；完成后提交差异、验证场景、已复用产物、失败样本和待实机项。共用数据改动沿依赖图重测受影响项。同一基线的一段可信回放可服务多个验收项，给每项记录自己的观察时间点。美术用固定状态比较，物理/数值用原始输入重算。签收优先级为核心玩法可读且好操作、可靠完成一局、可稳定出内容、最后再提升超出游戏镜头需求的细节。
