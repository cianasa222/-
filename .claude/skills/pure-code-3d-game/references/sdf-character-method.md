# SDF 人物方法 · 反橡皮人雕刻法（v4.2 新增， canonical）

> 来源：Cold Smoke 滑雪者方法；这是特定雪装有机人体配方，不是唯一通用路线。
>
> 一句话：**好的人物不是提示词写出来的，是 SDF 雕刻 + 骨骼姿态 + shader 材质 + 截图反馈迭代堆出来的。** 用户只说“做个滑雪者”，方法由 skill 扛住，不许把“写更细的提示词”当作解法。

## 1. 雪装配方的经验规则（仅适用于该配方）

1. 禁止胶囊/球体拼装：可见人物身体不得用 `CapsuleGeometry` / 等径胶囊 / 球体硬拼。`gamekit.mjs check` 对 character 模块静态拒绝 `CapsuleGeometry` 与 `BoxGeometry`。
2. 有机软组织宜 smooth union；硬表面和有意接缝可使用硬并集/CSG。
3. 雪装边界优先逐像素 SDF；其他可用独立裁片、真实拓扑、解析遮罩等，结果应无非预期锯齿。
4. 运动人物需要动作截图；T pose 可用于骨架诊断，不能独自代表最终动作效果。
5. 雪装可选择面罩、雪镜与手套；露脸是合法的独立设计选项，不需为遵从技能而改变用户需求。

## 2. SDF + smin 雕刻

身体由几十个图元拼成：椭球（三个半径独立）、变截面 tube（沿肢体方向半径插值，大腿 0.112→0.100→膝盖球 0.054）、圆角盒、球。全部用 Quilez 二次多项式 smooth-min 熔合：

```js
// smin(a, b, k)：k 是熔合区厚度（米）。k 越大越柔和、越小越保形状。
const smin = (a, b, k) => {
  const h = Math.max(k - Math.abs(a - b), 0) / k;
  return Math.min(a, b) - h * h * k * 0.25;
};
// GLSL 版同理：skMin(a, b, k)
```

k 取值 **0.012–0.08（1.2–8 cm 熔合带），分部位取不同值**：关节处小 k 保形状，躯干处大 k 求柔和。Quilez 的原话：硬并集只取最近者，smin 把两者熔合，“像黏土一样雕刻有机形状”；他的人脸示例里，硬并集时“所有基础图元清晰可见”，smin 后才“融合成一个连续表面”。

反橡皮人的造型意图（写进代码注释，逐条对照检查）：
- 衣领要高顶到头盔下，“头不是棍子上的球”；
- 臀部是一整块柔软体，“不是两个球”；
- 大腿“髋下一掌处最饱满、向膝盖收细”；袖子“从腋下向肘部收细、再到宽松袖口”；
- 头盔有壳、耳罩、帽檐、顶部通风脊；脸部开口是从壳里用 `smax` 做减法**切**出来的，不是贴上去的。

## 3. 比例写成硬常量（不许靠猜、不许用形容词）

```js
// 一个穿雪靴站上固定器的 1.76 m 成人；踝关节离雪面 0.16 m
const LEN = {
  thigh: 0.43, shin: 0.43,       // 大腿 = 小腿 = 0.43 m
  uarm: 0.30,  farm: 0.26,       // 上臂 0.30 m / 前臂 0.26 m
  grip: 0.075, ankle: 0.16,
  hipW: 0.09,  hipD: 0.05,       // 髋宽 / 髋深
  shW: 0.185,  shD: 0.05,        // 肩宽 / 肩深（肩比髋宽约 25%）
  spine: 0.25, chest: 0.25,
  neck: 0.085, head: 0.065,
  pole: 1.14,  basket: 1.05,     // 雪杖 / 篮筐位置
};
```

- 头身比约 **7.5**；肩宽约 2–3 个头、髋约 2 个头；腕对齐腹股沟、肘约在腰线。
- **剪影比例是第一眼“像人”的关键**：先用灰模 + 平光验剪影，剪影不对就不要往下做材质。
- 不同体型/生物另立 `AnatomyProfile`；不许把成人的 `LEN` 硬套给其他体型。

## 4. 骨骼、蒙皮与姿态求解器

- 约 **28 根骨骼**：骨盆、脊柱、胸、头、左右上臂/前臂/手、大腿/小腿/脚、雪杖、膝/肘辅助骨、臀、肩、颈、衣摆。
- **半程辅助骨**：膝、肘、髋、肩处各设半程坐标架，“让深弯像肢体一样折叠，而不是像被掐住的软管”；躯干前倾时夹克下摆沿臀部上滑（衣摆骨）。
- 蒙皮：每顶点最多 **3 根骨骼、指数衰减权重**，权重衰减区要够宽，“弯曲的关节是柔和曲线而不是折痕”；关节权重和须 ≈1。
- 姿态由求解器算出，不许手写坐标：双骨骼 IK、膝盖位置按雪靴约束求解、雪杖插杖轨迹用关键帧样条、临界阻尼平滑（动作切换不许 snap）。手握杖、脚踩板由求解器保证。
- 姿态来源优先真实姿态/mocap 参考；没有时先做一个“人物实验室”页面单独调姿态（tools/character-lab.html），调好了再接进游戏。
- 待机也要有生命：呼吸、换重心、看向目标、提杖放下——静止的人物一动不动也是橡皮感的来源之一。

## 5. 烘焙成 mesh（不是每帧 raymarch）

加载时以约 **13.5 mm 网格**把 SDF 烘焙成 mesh（手套等精细处可到 6 mm）；身体可在启动后台线程雕刻。缓存必须能删掉后由同一 Generator 版本、配方、Seed 重新算出来。烘焙网格是性能手段，不是“预制资产”——它来自公式，不是导入的模型。

## 6. 衣服细节放进 fragment shader

几何精度 13 mm 时，shader 细节是“不是塑料”的最强信号，且改 shader 比改几何便宜：

- 褶皱：`skFold()` 噪声沿肢体轴向成环，**弯曲越深褶皱越深**（肘/膝/髋）；缝线、拉链、拉链头、下摆抽绳扣、背包肩带 + 胸带 + 腰带 + 卡扣、裤侧口袋、雪靴卡扣、头盔通风口、耳垫、雪镜镜片、面罩针织纹、肩臂积雪、织物微浮雕——逐像素画。
- 服装边界逐像素用 SDF 重算（`skMin/skEll/skBox/skCap`），见 §1 第 3 条禁令。
- 材质：布料 wrap 漫反射、掠射角 sheen（逆光最强）、轮廓 rim 光、薄 shell 透光、由距离场本身算出的 AO、阴影；全身不得设为同等高光；未涂层金属和布料用各自的反射模型。
- 颜色与材质集中定义在一处（如 `SKIER_LOOK`），任何近距离展示同一套衣服的地方都按同一套来。

## 7. 人物设计：先选“能赢”的设计

- 厚衣服、无裸露皮肤、运动中、chase 镜头从后方拍、人物在画面中偏小、粉雪/雨雾/运动模糊遮挡。
- **先做到“从背后看像滑雪者”，再做正面；正面、特写、脸部最后才碰。**
- Cold Smoke 从未解决“画一张好看的脸”——它把脸藏起来了。这不是偷懒，是设计：脸和手是 AI 最容易翻车的两处，先把问题设计掉，再谈进阶。

## 8. A/B 对照

body / cloth / hand / kit 各留 a/b 两档（旧版/新版、平整/褶皱、方形拳头/手指握杖……），可在 dev 面板切换对比。每轮反馈只针对一个部位（先躯干、再腿、再手臂、最后头），避免“越改越糟”。

## 9. 不要做的事

- 不要在提示词里逐条描写眉毛、头发、睫毛等细节；细节是迭代中长出来的，不是提示词里写出来的。
- 不要指望一次生成；不要用“更详细的提示词”代替“看图修正”。
- 不要在剪影比例没过之前做材质；不要在姿态没过之前做特写。
