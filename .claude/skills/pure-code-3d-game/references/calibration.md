# 给开发 AI 的参数校准流程

从游戏设计目标、世界尺度、最近可用镜头、目标设备开始。tools/quality-example.json 全部数值都是演示预算。把候选值与来源、单位、适用对象、测量脚本和误差放在同一份项目配方；每项标注“设计目标／几何推导／实测”。修改验收预算必须有独立评审，禁止同一补丁放宽阈值来消除失败。

## 接触与碰撞

使用米、秒和固定 tick。分开角色移动体、受击体、攻击体、拾取触发器和表现网格；定义层间交互矩阵。记录脚底原点和偏移。直立人可用胶囊，radius 由躯干水平截面与玩法净空决定，height 为含端帽总高，圆柱段为 height−2×radius；车辆可用多个定向盒，简单弹丸用球或线扫。当前示例门禁描述代表性受测代理（capsule、box、sphere），复杂组合由项目单测各子形状。皮肤宽度是接触余量；跨台阶高度、最大坡角、地面吸附、重叠恢复按移动控制器分开设置。

先测最薄墙、最高相对速度及 tick。24 m/s 在 60 Hz 每步走 0.40 m，墙厚 0.12 m 时启动扫掠/连续检测；匀速单轴情况下，四次子步是 0.10 m/次。这个算式是风险筛查，不能证明转动目标和斜碰都安全。扫掠测试要用生产形状/相对运动求首次命中比例，初始重叠另行处理，滑墙保留切向速度。宽阶段用空间查询筛候选；装饰粒子只在玩法需要时查询简化碰撞。

必跑六组测试：满速正穿薄墙、擦角滑行、坡度阈值上下与台阶边界、静置接地、重叠出生、触发器/层过滤。冻结输入，记录 tick、法线、漏碰、最大残余穿透。重叠出生记录恢复后的穿透，另测恢复步数。将碰撞体叠在游戏画面上核对脚底、门宽与攻击距离。

## 人物细节

配方中的身高、肩宽、胸腰胯截面、肘膝位置与骨长驱动网格、装备插槽、步幅和代理。肩颈、髋与膝的大体块用渐变截面或局部 SDF，肘膝保留可弯曲拓扑；分离硬甲、裙摆、头发和软组织。用轮廓、接地和动作验收决定细分。例：1.75 m 人物在正式镜头只有 70 px 高，10 mm 特征正面投影约 0.4 px；纽扣雕刻可用材质表达，能改变外轮廓的头发、领口、肘膝值得几何预算。近景另测，不得靠无上限加面消除远处闪烁。

先用灰模与平光验剪影，再用同一机位的侧逆光检验皮肤、布料、金属是否可辨。材质配方记录 base color 空间、roughness、metalness、法线频率与 LOD。未涂层金属和布料应使用各自的反射模型，不能把全身设为同等高光。跑步、深蹲、转向、抬臂的接地窗口取自事件标记，测量支撑脚相对地面接触点的最大误差；运动平台使用平台局部坐标。验收包含实际游戏距离及动作峰值图，记录主体像素高度、实测身高、解剖错位、穿插与材质边界。纯展示实验室不能代替正式灯光、相机和蒙皮。

## 高质量特效

为每个特效写事件→预备→主体→余韵的时间曲线，记录发射空间、持续秒数、世界半径、颜色/亮度、透明度、扩张速度、粒子峰值、混合与深度策略。定义软粒子贴地过渡、透明排序、镜头过近和暗/亮背景的退化路径。示例命中由一条有方向的短线或网格、一道沿表面扩散的能量边与少量碎屑构成；第一帧同步命中事件。一个可调原型可取闪核 0–60 ms、冲击环 40–220 ms、碎屑 100–450 ms，按游戏节奏调整。过曝时调发光曲线与曝光，透明覆盖过大时先缩屏占比和寿命。

预警轮廓、命中时刻及作用半径在所有画质档一致；低档优先减少余韵粒子、二次火花和装饰雾，队友用独立通道。池化、实例化、距离裁剪减少分配与提交，仍要测透明像素过绘。固定回放/设备/相机/分辨率/档位，预热后交错测 FX 开关的帧时间 P95，记录样本数和峰值并发。P95 差值是配对场景的整帧差，不能当 GPU 专项计时。没有 GPU timer 就记未测；仅在代表性真机通过预算、预警可读且美术签收后宣布完成。

## v4.2 · 人物比例硬常量（新增）

人物比例不许靠形容词、不许靠猜，按以下常量写进角色配方；偏离须标注 `design-hypothesis` 并说明理由。来源：Cold Smoke `08_skier.js` 的 `LEN` 常量（实测核查）与成人解剖比例资料。

```js
// 1.76 m 成人；踝关节离雪面 0.16 m；单位米
const LEN = { thigh: 0.43, shin: 0.43, uarm: 0.30, farm: 0.26,
  grip: 0.075, ankle: 0.16, hipW: 0.09, hipD: 0.05,
  shW: 0.185, shD: 0.05, spine: 0.25, chest: 0.25,
  neck: 0.085, head: 0.065, pole: 1.14, basket: 1.05 };
```

- 头身比约 7.5；肩宽约 2–3 个头、髋约 2 个头；肩比髋宽约 25%；腕对齐腹股沟、肘约在腰线。
- 剪影验收先于材质验收：灰模 + 平光下剪影比例不对，禁止进入材质/特写阶段。
- 不同体型/生物另立 `AnatomyProfile`，不得把成人的 `LEN` 硬套给其他体型。

## 缓存与责任边界

为昂贵任务声明 inputs 和 deps，用 gamekit keys 计算传递依赖键。files 必须包括生成器、它导入的库、锁文件、配方、种子和影响结果的配置；toolchain 写实测版本。命中时还要验证产物存在和内容摘要，再复用。并发同键合并；失败不缓存，依赖不明时重建。材质变化影响着色与截图，骨长变化影响绑定、动作、接地、装备和相关碰撞。运行者负责实际缓存与执行；keys 仅计算指纹。改变玩法物理回放原始输入，改变美术可复用相同状态序列。发布前干净构建复测承诺设备，不以缓存代替发布验收。
