# Algorithm Registry / GameKit 4.7
先按 MODULES.json 加载专项模块。ALGORITHMS.json 是上游源码索引：repo、commit、path、license、复用模式与能力标签；构建链接 https://github.com/{repo}/blob/{commit}/{path}；只读取与任务相关源码，不把整个引擎塞进上下文。路径存在不代表完成审计；先检查内容、依赖、当前版本、授权和输入输出约定。GPL 插件仅参考一般方法与工作流程，禁止把实现/预设直接复制进不兼容许可的成品。MIT/Apache-2.0 允许按其条件复用，保留版权、许可证与适用 NOTICE；第三方文件逐项检查。本文不安装完整引擎，不声称已移植上游。
优先已有通过项目测试的库/原生 API，其次独立可复用组件，最后才重写；禁止只因新上游存在就迁移正在工作的项目。GameKit 纯代码约束不变：引擎、数学库、算法源代码可依法复用；外部预制可见网格/纹理/动作/特效/音频不能作为严格 code-only 游戏素材。算法计算产生的缓存可以复算。
所有组件记录单位、坐标、时间模型、随机种子、输入范围、容差、版本、平台与性能；从 CPU 参考到 GPU/WASM 的迁移先验证等价。对跨引擎适配器保留原始接口与实际验证。真实画面、GPU 性能、终端设备验收未完成不得报告 PASS。ComputeKit v4.6 自主调用规则不变。
