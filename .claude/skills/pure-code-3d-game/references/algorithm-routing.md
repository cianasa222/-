# 通用数学算法路由（独立于引擎）
先按 brief 定义单位、参考尺度、观看距离、移动、质量和预算，白模→主轮廓→接触/碰撞→次要结构→材质/光影→细节；对象写生成器 ID、部件树、尺寸、父子关系、接触点、LOD、Seed 和参数来源。根据对象选择算法，而不是一律 SDF。
- 硬表面/建筑/机械：参数化 CSG/Manifold、布尔、倒角、样条扫掠、模块语法。检查封闭性、法线、尺寸和物体接地。
- 有机身体：分段 loft/样条截面、参数曲面、SDF smooth union、隐式面提取；可组合，分辨率按镜头校准。避免未融合原始体冒充精细有机人物。
- 人脸：参数化头颅、五官、眼睑、鼻唇、下颌、耳廓；可采用风格化或遮面方案，但不能强迫藏脸；近景另设轮廓、表情和皮肤验证。禁止导入密集扫描、人体模板顶点或预制 blendshape 作为纯代码来源。
- 植被：L-system/递归分枝、曲线扫掠叶片、种子化 Poisson/网格散布、GPU instancing、LOD、风场位移；生成一次，动态只更新必要数据。
- 地形：fBm、domain warp、ridged noise、水力/热侵蚀（预算内），高度场和 SDF 分别处理地面与洞穴；共享视觉/碰撞采样。
- 水：Gerstner 波叠加、FFT 按规模选；法线从偏导，Fresnel、深度吸收、泡沫/岸线；海况参数来自设计/物理范围，不把特定 raea 性能数字当通用。
- 云雾天气：3D 噪声、密度场、体积步进/光照、时间重投影、粒子批处理。低端可用解析近似，不伪造体积效果。
- 布料：裁片参数、厚度/弯曲/伸长约束、XPBD、碰撞、骨骼附着；毛发曲线与束、风和 LOD；材质以程序函数生成。
- 音频：振荡器、噪声、包络、滤波、调制、程序混响和空间化；按模拟事件触发，固定 Seed 可回放。
- 玩法：state step(state,input,tick,seed) → next state；渲染只读，稳定 entity ID，输入脚本和事件；支持可控浮点容差。ECS/SoA 用于规模化实体，避免每实体跨语言调用。
质量底线和艺术选择分离。参考 Cold Smoke、raea 方案只是候选；不强制镜头、角色身高、风格或固定引擎。真实参数优先可追溯测量；未知值标 design-hypothesis 并可配置。不要把参考图、外部预制模型、动作帧或样本数据打包入 code-only。
