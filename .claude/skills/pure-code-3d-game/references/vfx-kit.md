# VFXKit：参数化效果
Effekseer 的层次发射、曲线、力场与 Ribbon/Track 思路用于设计 EffectRecipe：seed, duration, emitter rate/burst/shape, lifetime/speed/size, local/world space, gravity/drag/wind/curl, color/opacity/scale curves, material/blend, child triggers, ribbon width/history, collision/kill, bounds/LOD/budget。严格模式不导入现成 .efkefc、贴图、音频等；可使用程序构造的数据和 shader。tools/vfx-kit.mjs 是独立 CPU 基准：固定 dt、确定性 LCG、球方向发射、速度/寿命随机、半隐式积分、寿命回收、粒子上限和丢弃计数、分段线性曲线。尚无层级、Ribbon、GPU、材质绘制或完整 runtime。生产时测量 overdraw、draw calls、spawn budget、内存；拖尾用历史点生成连续带状几何，稳定切线/法线和 UV；场景碰撞需实际引擎。GPU 版使用 SSBO/storage buffer、双缓冲或无竞争原地更新；相同 seed、固定步和容差比较 CPU baseline，GPU 浮点与不同随机算法不得假定逐位一致。
