# 程序化光照与阴影

## 先选适合场景的光源

固定摄影机、单位和输出变换，放一个漫反射灰球、一个粗糙金属件和一个带底座的人物替身。分别看直射、环境、可见度、最终合成四张图。主角进阴影应保留材质层次，鞋底与地面接触应连贯。把这组标尺和代表性游戏镜头都保存，换天气以后仍可重放。

- 户外采用一个主方向光；同一份时间/天气状态驱动天空、雾、环境辐照和曝光。预算紧可预设正午、黄金时段、阴天三套线性 RGB 辐照值，平滑插值；需要连续昼夜与地平线散射时再做大气 LUT。记录 LUT 对太阳高度、月光、气溶胶等实际输入的依赖，按可见误差更新。方向光变化仍需逐帧正确传给着色器。
- 固定室内优先程序烘焙的辐照探针或分区环境光，仅为实际投射轮廓的灯启用局部阴影。装饰灯的自发光和辉光可独立存在。移动角色按位置插值取探针值；跨门洞测试漏光。积雪的地面反照应换成项目实际地表。
- 在场景线性空间计算：漫反射环境项可按法线向上分量混合天光和地面反照；主光直射乘材质 BRDF、入射角和阴影可见度。环境镜面依粗糙度取过滤后的天空或环境表示。遮蔽影响间接光的局部可达性，同一接触区域避免再叠一层重黑。统一在末端做曝光、色调映射、显示色彩变换。实验室提供简化的漫反射路径；生产材质应接回项目的 BRDF。

## 方向光阴影的最小实现

1. 依据游戏镜头选接收阴影的范围，加入可遮挡这些接收者的离屏投影物。用裁剪后的正交光视锥单独渲染深度。明确 OpenGL 与 WebGPU 裁剪空间深度、纹理 Y 方向和反向 Z 比较方向。参考 JS 的方向朝向光源，OpenGL NDC Z 为 −1…1。
2. 固定视锥宽度 W，边长 N，光空间一个阴影纹素等于 W/N 米。将中心投影到光空间横纵轴，取 round(center/texel)×texel，对齐绝对世界坐标后再减浮动原点。低角度时接收面上的纹素可能明显拉长。在固定太阳下慢移相机，看阴影边缘是否爬动。动态方位与正上方附近另测光空间基向量的连续性，可沿用上一帧投影基并连续更新相位。示例小实验室只覆盖受控太阳轨道。
3. 接收端投影世界点、采样深度，使用小常量和随坡度调整的偏差以抑制自阴影条纹。对正交标准深度，光空间深度偏差米数除以 far−near。三角上的斜率、物体尺度和薄片需实测。看脚底和薄栏杆同时调，避免用过大 bias 造成影子脱离。采用相邻深度比较的平均值（PCF）得到边缘过渡。近景窄核保贴地感，预算充足再用遮挡距离近似拓宽半影。裁剪边界淡出或与较远级平滑接续。
4. 移动人物、投影物、主光方向、吸附后的投影矩阵或投影物 LOD 变化会让相关深度图失效。仅改曝光、主光颜色、补光、阴影强度时可复用已有深度。静态/动态是否拆层由测量决定；若拆分，比较深度或合成可见度时注意遮挡关系。单视图已有每帧一次的全局阴影时，不再为每个材质、反射预览或第二只眼无条件重画。
5. 区分“阴影强度”和“阴影开销”：强度调可见度插值，地图尺寸、投影范围、投影物集合和比较次数决定主要成本。低档优先缩远处范围、降低远处更新频率，保留脚底、危险提示和玩法可见性。

## 工具与验收

tools/light-rig.mjs 含方向光矩阵、世界纹素吸附以及可移植的 WebGL2 GLSL PCF 函数。tools/lighting-lab.html 用同一模块渲染原创灯塔、地面和岩块。用静态服务器提供 tools 目录后打开 lighting-lab.html。分别调整日照角度、天空补光、深度尺寸与阴影强度，观察深度图绘制次数及暗面层次。只在参数或窗口改变时重绘。

3.2 新项目在 quality-contract.json 声明 lighting 以及每个启用目标的 shadowBudget（单位米、毫秒、像素）；3.1 旧项目沿用已有契约，升级光影时显式补上该组字段。验证器按每个目标检查地图实测尺寸、覆盖宽度、锁相机实测脚底影隙、相机慢移时的边缘抖动、场景关键区域的亮暗细节、配对开关阴影的整帧 P95 及帧数。建议用道具底部和固定世界接收点的屏幕投影作基准，扣除正常的相机运动；不要把昼夜导致的合理投影移动算成闪烁。亮暗细节用固定标尺、固定曝光、手工复核。切换阴影强度时核查玩法可读性。证据须来自真实目标，数值与人工复核分开记录。

WebGL2 手动比较深度时，采样器明确使用 highp sampler2D。片元 float 的默认精度并不能代替采样器的精度声明。实验室在平地出现过重复条纹，把采样器改为 highp 后通过软件光栅图像对照。示例 PCF 也按接收平面的深度梯度校正各采样点。诊断时先看深度和接收面，再调整 bias 与投影范围，保留同机位开关对照。
