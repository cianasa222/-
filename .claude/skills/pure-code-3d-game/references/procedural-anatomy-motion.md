# AnatomyKit / MotionKit · 数学人物与动作设计

## 参数的来源不等于「把来源模型下载给游戏」

`RigRecipe` 用角色设计目标（实际镜头下的头身比、肩/髋宽度、关节几何）、解剖学量化研究与自有实测校准。每项具有 SI 单位、来源、适用的生物类型、误差或 `design-hypothesis` 标记。程序运行时接收配方和 Seed，自己生成骨骼、网格、权重。**不得直接从 MakeHuman/VRM/Mixamo 导入整套模型、绑定权重或动作帧；只可研究骨命名语义、解剖关系和求解算法**。

人形只是一个 Profile。昆虫、四足、机械臂必须有独立 `AnatomyProfile`；不能强迫全部采用《雪迹》的 59 骨结构。一个人物可按不同镜头使用不同骨骼密度，但这些骨骼来自相同设计约束。默认 Y-up、米、弧度、统一 Driver Rig；后端渲染不改变 pose 语义。

## Cold Smoke 雪装可选配方（不是通用限制）

可选厚衣、头盔、面罩简化远景人物；露脸或其他风格用独立参数化面部配方。不能以简化规避用户要求。

雪装示例比例与骨骼见 references/sdf-character-method.md；通用参数见 references/rig-motion-kit.md。

```js
// 1.76 m 成人；头身比约 7.5；肩比髋宽约 25%
const LEN = { thigh: 0.43, shin: 0.43, uarm: 0.30, farm: 0.26,
  grip: 0.075, ankle: 0.16, hipW: 0.09, hipD: 0.05,
  shW: 0.185, shD: 0.05, spine: 0.25, chest: 0.25,
  neck: 0.085, head: 0.065, pole: 1.14, basket: 1.05 };
```

雪装示例约 28 根骨骼、半程辅助骨及三骨权重；其他体型、动画、镜头可配置骨数与权重方法。优先 IK 接触约束。

按项目风格选择使用；它们仅为数值原型，不是完整美术级面部。

## 无预制动画帧的动作生成

完整纯程序动作不播放「固定 30 FPS 逐帧骨骼曲线」。把动画拆成动作意图与约束：

- **运动意图**：move/turn/jump/attack/look/grab、目标、速度、停止距离和事件。
- **步态参数**：人体尺寸→腿长及步长设计；速度→节拍/周期；左右脚用半周期错相。每脚随 `stance/swing` 进入不同求解模式。
- **根部运动**：移动控制器决定根位移和动力学，不由视觉动画偷改 authoritative 物理状态。
- **接地**：支撑脚在地形局部坐标固定世界位置；摆动脚沿可调起落轨迹移动，求解足跟/脚尖/法线约束，不滑地。
- **逆运动学**：两骨膝肘 IK、肩/髋姿态、脊柱补偿；复杂动作采用 CCD/FABRIK 和关节极限。站姿和奔跑要允许不同风格化变形，但不能折断肢体。
- **姿态混合**：状态之间基于姿态/速度连续插值，攻击/瞄准可用受限动作层；一具身体只有统一相位钟与最终约束所有者，禁止叠层 spring 互相抢结果。
- **可重复性**：Pose = f(recipe, seed, authoritative simulation time, movement state, contact state)。禁止用 `Math.random`、帧率相关积分或复制现成 mocap 输出冒充计算方法。

`sampleWalk` 是**二维水平面步态的验证参考**，只表达步态相位、全局固定支撑脚、上下两段腿 IK 和可复现位置。它不包含侧步、转弯、跑步、手臂摆动、上下坡足旋转、真实身体惯性和完整动画混合。达到高品质须由 MotionKit 后续版本逐项扩充并通过真实 GPU 渲染验收。

## 数值验收策略

- 检查骨长和关节位置是否稳定；所有 mesh vertex/index/normal、关节变换和 IK 目标有限且在合法范围；接触足世界滑移在锁定的支撑时间窗口内不超项目阈值。
- 对两个不同身高的身体配方，在固定相同世界速度/地形下回放一次姿态序列，记录 `unreachableIK`、`jointLimitViolations`、`penetrationDepth`、`footSlip` 与动画动作切换瞬态。
- 每个场景输出完整身形/头盔·雪镜近景/3/4/侧/逆光/运动高应力姿势对比；美术验收明确是否存在方块人、SDF 泥人、脚滑、肘膝弯反、头颈失联、服装边界锯齿。
- 所有未经实测的身体参数、脚滑阈值、性能指标写为初始设计假设，并锁定目标相机与设备后校准，**不允许 AI 为了过关私自抬高阈值**。
