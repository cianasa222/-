# 交接文档：《幻听》DJ 版 MV

新会话请先完整读完本文件，再动手。所有要求都来自用户，已经确认过，不要擅自改方向。

## 1. 这是什么
- 一段 30.6 秒的 MV，歌曲是《幻听》DJ 版片段（129 BPM，每拍约 0.4645 秒，每一拍都有底鼓）。
- 画面全部用代码渲染：3D 部分用 three.js，2D 部分用 HTML/CSS/Canvas，Playwright 逐帧截图，ffmpeg 合成。
- 成品规格：1280×720、60 帧、带歌曲。
- 用途：用户个人观看，不盈利。

## 2. 用户已经确定的要求（必须遵守）
- **两个形象**
  - 3D：光滑细腻的圆角方块小人（不是一颗颗小方块拼的），软胶质感，竖条小眼睛，腮红，两侧小凸起，短腿，Q 弹的果冻动效。
  - 橙色小人戴奶白色粗软头带 + 大圆耳罩（橙色外壳，音符灯）；粉色小人同款情侣耳机（粉色外壳，爱心灯）。
  - 两个小人身上都有一点微光。橙色亮度要够（不能暗），粉色是半透明的「幻听」，比橙色暗一些，**脸、眼睛、腮红必须看得清，要经常露正脸，不能只有侧面**。
  - 2D：像素小人（橙色身体 + 奶白耳机 + 腮红），只出现在 2D 桌面里。
- **画面**：参考的是「质感」：光照、景深、精细度；不照搬任何参考视频的场景和设计。
- **亮度**：不能亮到看不清脸和歌词。
- **卡点**：DJ 版，每一拍都要有动作；镜头从头到尾一直在动，直到结尾。
- **动作**：要大幅动效，**不能傻站着**。
- **歌词**：逐字卡点，带弹出、蹦出特效；按含义上色（爱=粉、不在/失落/难过=蓝、一个人/夜色/过往=淡紫、耳边/温柔=暖桃、走脱/歌=金、流动=浅青），每个字有深色描边保证可读。
- **2D/3D 衔接**要高级自然：现在的做法是 3D 撞进「幻听」方块 → 侧面特写像素网格扩散 → 碎成方块 → 3D 画面马赛克化（40px）→ 从中心逐块翻转成 2D（翻转时方块边缘闪光）→ 碎片在 2D 里重组成像素小人。结尾反向。
- 2D 界面配色和 3D 夜景一致（靛紫/薰衣草夜空、月亮、星空、体素山剪影、和歌河同款的发光方块频谱）。

## 5. 文件
- `mv.html` 总控（3D 歌词、方块翻转转场、闪光、淡出）
- `world.js` 3D：场景、两个小人、筏子、踏脚方块、脚印、粒子、按拍子的动作编排（`stateOrange`/`statePink`）、跟拍镜头（`RIGS`）
- `desk.js` 2D：播放器界面、像素小人动画（`EVENTS` 跳跃事件表、`spriteAt`）、运镜关键帧（`CK`）
- `timeline.js` 节拍、逐字歌词时间、歌词配色
- `render.js` 逐帧截图（可断点续渲）
- `analysis.json` / `lyrics_timing.json` 节拍和歌词时间
- `huanting_mv_60fps.mp4` 上一版成片（动作较少的旧版），也是歌曲音频的来源

## 6. 在 Windows 本地渲染（全部放在 C:\七星）
用户电脑：i5-13500H、16GB 内存、Intel Iris Xe 核显（没有独立显卡）。用户要求所有东西装在 `C:\七星` 里，装任何东西之前先告诉用户。
1. 免安装版 Node.js（20 以上）解压到 `C:\七星\node`；ffmpeg（7 以上）解压到 `C:\七星\ffmpeg`；npm 缓存设到 `C:\七星\npm-cache`。
2. 把本文件夹（mv-huanting）放到 `C:\七星\mv-huanting`，在里面：
   ```
   set PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1
   npm i
   ```
   用系统自带的 Edge，不用下载浏览器。
3. 先试渲 3 张静帧看速度和画面（3D 部分用核显）：
   ```
   set RENDER_BROWSER=msedge
   node render.js mv.html stills stills 3.5,7.4,18.0
   ```
4. 正式渲染（可断点续渲，中断后重跑同一命令会跳过已有帧）：
   ```
   set RENDER_BROWSER=msedge
   node render.js mv.html frames range 0 30.6 60
   ```
5. 取出歌曲音频并合成：
   ```
   ffmpeg -i huanting_mv_60fps.mp4 -vn -c:a copy song.m4a
   ffmpeg -framerate 60 -i frames/f_%05d.png -i song.m4a -t 30.6 -c:v libx264 -crf 17 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart mv_v2.mp4
   ```
6. 1836 张 PNG 约 2–3GB，合成完可以删。

## 7. 注意
- 仓库是公开的，用户知道并同意把成片推上来。
- 字体用的是 Noto Serif SC（npm 包 @fontsource/noto-serif-sc），歌词才能显示正确。
- 如果画面和云端渲染不一致（核显和软件渲染的光照可能略有差别），以「脸和歌词看得清、不过曝」为准微调 `world.js` 里的灯光和泛光。
